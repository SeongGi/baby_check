# 설계

## 음성 흐름
1. 앱이 전면에 오면 기존 설정에 따라 듣거나 사용자가 마이크를 누른다.
2. 한 번의 발화를 파싱해 명령 종류와 필수 값을 구한다.
3. 필수 값이 충분하면 화면에 값과 `기록 확인`을 표시한다. 부족하면 저장 대신 안내를 표시한다.
4. 확인 시 기존 `onAddLog`/`onUpdateLog`를 통해 저장한다.

## 명령
- 수유: `분유 120ml 먹었어`, `모유 80ml 먹었어`, `분유 80 모유 40 먹었어`.
- 기저귀: `소변 기저귀 갈았어`, `대변 봤어`, `노란색 묽은 대변 많이 봤어`. 음성에서 누락된 세부값은 `미입력`으로 표시하고 확인 화면에서 선택해야 저장된다.
- 목욕: `목욕 10분 했어`, `간단 씻기 5분 했어`.
- 몸무게: `몸무게 5.2kg 기록`.
- 시간 기록: `지금 자`, `지금 깼어`, `터미타임 시작/끝`, `놀기 시작/끝`.

## 안전성
- 시작/종료 중복은 저장 직전 가장 최근 상태를 재검증한다. 종료 시각은 시작 시각보다 빠를 수 없고 다른 화면에서 상태가 바뀌었으면 저장하지 않는다.
- 소변·대변의 누락값과 목욕의 누락 시간을 `미입력`으로 표시하고 사용자가 선택하기 전에는 저장하지 않는다.
- 부정·질문·복수 명령은 `unknown`으로 두고 저장하지 않는다.

## Google Home
Google Conversational Actions는 2023-06-13 종료되었다. App Actions는 Android 앱 기반이고 스피커에서 동작하지 않는다. Google Home Cloud-to-cloud는 스마트홈 기기 및 정의된 특성 제어용이므로 육아 기록 자유 발화를 전송할 수 없다. 따라서 스피커 직접 기록은 현재 공식 지원 경로가 없다.
