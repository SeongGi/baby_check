# 모든 기록의 앱 내 음성 입력

## 목표
- 대시보드 음성 입력에서 수유(분유·모유·혼합), 소변, 대변, 목욕, 몸무게, 수면, 터미타임, 놀기시간을 기록한다.
- 인식 결과와 채워질 값을 확인한 뒤 사용자가 저장한다.
- Google Home 스피커 직접 기록의 공식 지원 여부를 조사한다.

## 제외
- Google Home 스피커가 휴대전화 앱으로 발화를 전달한다고 가정하지 않는다.
- Google Home 스마트홈 기기인 척하는 우회 연동을 만들지 않는다.
- 모호하거나 누락된 측정값을 추측해서 저장하지 않는다.

## 성공 기준
- 각 로그 종류의 명령이 유효한 데이터로 변환되고 저장 전 확인된다.
- 수면·터미타임·놀기시간의 시작/종료 상태를 안전하게 처리한다.
- 인식 불가·값 누락·범위 오류는 저장되지 않는다.
- 타입 검사와 관련 명령 테스트가 통과한다.

## 운영 위험과 열린 질문
- 실제 휴대전화의 음성 인식 품질은 기기별로 다르므로 실기기 검증이 필요하다.
- Google Home의 Conversational Actions는 종료되어 현재 공식 경로로 자유 발화 기록을 받을 수 없다.
- 대변 색과 상태, 소변 세부 상태를 말하지 않은 경우 `미입력`으로 보이고 확인 화면에서 선택하게 한다.
