# Alpha 시제품 배포

- 대상: Google Play 비공개 테스트 Alpha, 버전 1.7.2 / 코드 20
- 출시 노트 초안: `앱을 열 때 음성 입력을 자동으로 시작하는 선택 기능을 추가했습니다. 인식한 분유량과 수면 기록은 확인 후 저장됩니다.`
- 설정 위치: 홈 → 빠른 기록 → 앱을 열 때 바로 듣기
- 시험 문구: `헤이 구글, 아기기록 열어줘` → 앱에서 `분유 120ml 먹었어`, `지금 자`, `지금 깼어`
- 제약: Google 호출 문장이 그대로 앱에 전달되지 않으며, 설정을 켜면 평소 앱 실행에도 듣기가 시작된다.
- 실제 제출 및 검토 상태: 진행 중.
