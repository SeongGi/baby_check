# 구현 계획

1. 자동 시작 요청과 설정 저장을 MainApp에 추가한다. 검증: `npx tsc --noEmit`.
2. 홈 VoiceLogButton에 토글과 요청 소비를 연결한다. 검증: `npx tsc --noEmit`.
3. 앱 시작/복귀/화면 재방문/권한 실패 흐름을 검토한다. 검증: 기존 음성 파서·동기화 테스트, Android 번들 또는 APK.
4. 독립 코드 검토 2건과 임시 변이 검사를 수행한다. 결과는 `04-검증.md`에 기록한다.
5. Android 서명 번들을 만들어 Alpha 트랙에 제출하고 검토 상태를 확인한다. 기기에서의 실제 Google 호출은 사용자가 확인한다.
