# Google 호출 후 음성 기록 요구사항

## 목표
- Android에서 사용자가 "헤이 구글, 아기기록 열어줘"로 앱을 열었을 때, 사용자가 선택한 경우 홈 화면의 한국어 음성 인식을 자동으로 시작한다.
- 인식 결과를 확인한 뒤 기존 음성 기록 저장 버튼으로 저장한다.
- 앱 내부에서 자동 시작을 켜고 끌 수 있고, 선택은 기기에 유지된다. 기본값은 꺼짐이다.

## 하지 않을 것
- Google/Gemini가 한국어 명령의 분유량이나 수면 상태를 앱에 직접 전달한다고 주장하거나 구현하지 않는다.
- 확인 없는 자동 저장, 잠금 화면 뒤에서의 녹음, 상시 마이크 대기는 하지 않는다.
- Google Play Alpha 비공개 테스트 트랙에만 제출한다. 프로덕션 출시는 하지 않는다.

## 성공 기준
- 자동 시작을 켠 상태에서 앱을 새로 열거나 백그라운드에서 홈 화면으로 복귀하면 인식이 한 번 시작된다.
- 끈 상태에서는 기존 버튼 동작만 한다.
- 권한 거부/서비스 없음에서도 앱이 계속 작동한다.
- 홈 화면을 단순히 다시 방문하거나 설정을 켠 직후에는 자동 인식하지 않는다.

## 운영 위험과 열린 질문
- 일반 앱 실행과 Google 호출을 앱에서 구별할 수 없어, 켜 둔 경우 일반 실행에도 자동 인식한다.
- Google이 한국어 앱 열기 요청을 인식하는지는 기기/계정의 Assistant 또는 Gemini 설정에 달려 있다.
- 실제 Google 호출과 음성 인식은 사용자 Android 기기에서 확인해야 한다.
- 기존 Alpha 1.7.1 검토 상태를 확인하고, 다음 버전 코드로 제출한다.
