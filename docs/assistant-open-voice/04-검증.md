# 검증 기록

## 통과
- `npx tsc --noEmit`
- `node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON tests/voiceCommand.mjs`: 8개 사례 통과
- `bash tools/sync-harness/verify.sh offline`: 단위 18/18 및 회귀 통과
- `npx expo export --platform android --output-dir /tmp/baby-check-assistant-export`: Android JS 번들 생성
- `JAVA_HOME=... ANDROID_HOME=... ./gradlew :app:assembleDebug`: Android 디버그 APK 생성
- `./gradlew :app:bundleRelease`: 서명된 1.7.2 / 코드 20 AAB 생성. `jarsigner -verify`: `jar verified`; 이전 출시 번들과 동일한 서명 인증서 SHA-256 `6A:92:D3:E2:85:E2:4B:F9:F2:86:E7:8E:93:5D:04:34:F7:5C:62:C3:32:6B:F1:28:3A:21:5C:F4:48:09:ED:73`.
- 병합 AndroidManifest에서 마이크 필수 하드웨어 선언 `required=false` 확인.
- 음성 명령 파서의 최소 분유량 조건을 안전하게 임시 변경하면 사례 검사가 실패함을 확인하고 즉시 원복. 원복 후 사례 검사 재통과.
