# 1.7.9 구현 계획

1. `KeyboardAwareScrollView` 공용 컴포넌트를 추가하고 분유·기저귀·목욕·체중·설정 화면에 적용한다.
2. 홈의 기록 수정 모달과 다음 수유 시간 모달에 `behavior="padding"`을 두 플랫폼 모두 적용한다.
3. 체온 기록(타입, 입력 화면, 홈, 수정 모달, 통계)을 추가한다. 설계를 확정한 뒤 t1-worker(Sonnet)에게 구현을 맡기고, 돌아온 diff는 직접 검토한다.
4. 원스토어 빌드 구분(`EXPO_PUBLIC_DISTRIBUTION_STORE`)과 `docs/ONESTORE_RELEASE.md`를 추가한다.
5. 버전을 1.7.9(코드 27)로 올린다. `app.json`의 `versionCode`가 24로 남아 있던 것도 27로 맞춘다.
6. 검증: `tsc`, 음성 테스트 3종, 동기화 하네스, 에뮬레이터 스크린샷, 임시 코드 변이를 진행한다.
