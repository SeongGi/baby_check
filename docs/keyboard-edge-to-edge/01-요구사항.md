# 1.7.9 요구사항: 키보드 가림 재수정, 체온 기록, 원스토어 준비

## 1. 목표
- 분유를 비롯한 기록 화면에서 입력창을 누르면, 키보드가 올라와도 입력창이 키보드 위에 보여야 한다. 1.7.8에서 같은 문제를 고쳤지만 Android 실기기에서 다시 신고되었다.
- 아기 체온을 기록하고, 홈 목록과 통계에서 확인하고, 수정·삭제할 수 있어야 한다.
- 구글 플레이 심사가 오래 걸리므로 원스토어 출시를 병행할 수 있게 빌드와 문서를 준비한다.

## 2. 하지 않을 것
- 기존 기록 종류의 데이터 구조와 동기화 코드는 바꾸지 않는다.
- 체온 음성 명령과 위젯 표시는 이번 범위에서 제외한다.
- 원스토어 계정 가입, 상품 등록, 심사 요청은 사용자가 직접 한다(계정과 결제 정보가 필요하다).

## 3. 성공 기준
- 에뮬레이터에서 분유 메모, 기록 수정 모달 메모, 체온 입력 시 입력창이 키보드 위에 보인다(스크린샷).
- 체온 34~42℃만 저장되고, 38℃ 이상이면 안내 문구가 보인다.
- `npx tsc --noEmit`, 음성 테스트 3종, 동기화 하네스가 모두 통과한다.

## 4. 운영 위험
- 실사용자 데이터 손실 금지: 구버전 앱이 체온 기록을 받아도 저장소 검증은 `type`이 문자열인지만 보므로 기록을 지우지 않는다. 다만 구버전 목록에서는 내용 없이 보인다.
- 원스토어 설치본과 Play 설치본은 서명이 다를 수 있다. 서명이 다르면 기존 Play 사용자가 원스토어 버전을 설치하려면 앱을 지워야 하고, 앱을 지우면 기기에 저장된 기록도 함께 지워진다.
