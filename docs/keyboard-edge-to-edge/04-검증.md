## 4. 리뷰
- 체온 기록 diff를 직접 검토했다. 동기화 코드는 기록 객체를 통째로 보내므로 `temperatureC`도 그대로 전달된다. 구버전 앱의 저장소 검증은 `type`이 문자열인지만 보므로 체온 기록을 지우지 않는다.
- 빌드 도중 `expo run:android`가 prebuild로 `android/`를 덮어쓴 일이 있었다. `git checkout -- android/`로 되돌렸고, 추적하지 않는 `MainActivity.kt`도 원래 저장소의 파일로 맞췄다.
