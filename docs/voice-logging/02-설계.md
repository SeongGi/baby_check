# 음성 기록 설계

## 결정
Expo SDK 56 호환 `expo-speech-recognition` 56.x를 이용해 기기 음성 인식을 시작한다. 최종 전사만 명령 파서에 넣고, 확인 화면에서 저장한다. Gemini API 키와 서버는 필요하지 않다. 앱의 기존 `onAddLog`/`onUpdateLog`를 재사용하여 가족 동기화와 알림 갱신을 유지한다.

## 흐름
음성 버튼 → 권한 요청 → ko-KR 단일 발화 인식 → 전사 표시 → 제한된 명령 파싱 → 동작 확인 → 기존 저장 경로.

수면 종료는 진행 중인 가장 최근 수면 로그의 `endedAt`을 현재 시각으로 갱신한다. 현재 수면 상태와 명령이 어긋나면 저장하지 않고 설명한다. 분유량은 10~500ml 정수만 허용한다.

## 독립 검토
1차 설계 검토: Google App Actions custom intent의 한국어 미지원이 확인되어 앱 내부 인식으로 변경. 임의 전사를 곧바로 저장하지 않도록 확인 단계를 추가. 승인.
