# 음성 기록 요구사항

## 목표
- Android 앱 안의 음성 버튼에서 한국어로 “분유 120ml 먹었어”, “지금 자”, “지금 깼어”를 말해 기존 기록 저장 경로로 등록한다.
- 인식 결과와 해석한 동작을 저장 전에 화면에 보여주고 사용자가 확인한다.
- 수면 시작 중복, 수면 종료 대상 없음, 분유량 범위 오류를 막는다.

## 범위 밖
- 앱을 열지 않고 “헤이 구글”로 호출하는 기능, Gemini API 연결, 상시 대기 및 백그라운드 녹음.
- 추가 기록 유형과 자연어 시간 보정.

## 성공 기준
- 한국어 세 명령이 올바르게 해석되고 확인 후 기존 동기화 경로로 저장된다.
- 권한 거부, 인식 실패, 모호한 문장에는 기록을 만들지 않는다.
- 타입 검사와 기존 회귀 테스트를 통과한다.

## 운영 위험과 열린 질문
- Android 음성 인식 서비스와 인터넷 상태에 따라 인식 품질이 다를 수 있다.
- 실기기에서 ko-KR 인식, 권한 문구, 앱 재빌드 여부를 확인해야 한다.
- Google Assistant App Actions의 custom intent는 en-US만 지원하므로 한국어 호출은 별도 검토가 필요하다.
