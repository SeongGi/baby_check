# Google Play 출시: 음성 기록

## 대상
- 앱: 아기기록 (`com.seonggi.babycheck`)
- 트랙: 비공개 테스트 Alpha (프로덕션은 테스터 참여 요건 미충족으로 비활성)
- 새 버전: 1.7.1 / versionCode 19 (코드 18은 제출 전 기기 호환성 경고를 발견해 교체)
- 소스: `feat/voice-logging`의 음성 기록 기능, 검증 완료 후 master SHA 고정

## 스토어 출시 노트
음성으로 분유량과 수면 시작·종료를 빠르게 기록할 수 있습니다. 인식한 내용을 확인한 뒤 저장하며, 음성 기록의 안정성을 개선했습니다.

## 출시 전 검증
- TypeScript 검사 통과, 음성 명령 8개 사례 통과
- 동기화 단위 18개 및 회귀 검사 통과
- Android 번들 생성 통과

## 제출 및 사후 확인
AAB 서명·버전·SHA 확인 후 Play Console Alpha 트랙에 업로드한다. 검토 제출 뒤 상태와 개인정보처리방침 공개 페이지를 확인한다.

## Play 미리보기에서 발견한 기기 호환성 문제
코드 18 AAB를 임시 출시로 업로드한 뒤, Play가 기존 지원 기기 16대를 제외한다고 경고했다. `RECORD_AUDIO`에서 마이크 하드웨어 필수가 추론되는 문제로 확인했다. 마이크를 선택 기능(`android.hardware.microphone`, `required=false`)으로 선언하고 코드 19 AAB로 교체한다. 코드 18은 검토 제출하지 않았다. 코드 19의 병합 매니페스트와 서명을 확인했다.
