# 음성 기록 포용력 확대 및 즉시 저장 구현 계획

## 단계별 계획 및 검증 명령

### 1단계: 파서 확장 및 기본값 정리 (`src/utils/voiceCommand.ts`)
- 자연어 패턴 포용력 확대:
  - 수유: "분유 160", "맘마 140", "우유 120", "모유 100", "수유 150ml 먹었어" 등 단위 생략 및 어미 유연화
  - 기저귀: "쉬했어", "쉬야", "오줌", "응가했어", "똥 쌌어", "기저귀 갈았어" 등 지원
  - 수면: "낮잠 시작", "밤잠 시작", "기상", "일어남" 등 지원
  - 목욕/체중/터미타임/놀기 어미 유연화
- 기본값 처리:
  - 소변: `wetness: 'medium'`, `color: 'normal'` (기본값 제공)
  - 대변: `color: 'yellow'`, `consistency: 'soft'`, `amount: 'medium'` (기본값 제공)
  - 목욕: `durationMinutes: 10`, `bathType: 'full'` (기본값 제공)
- 검증: `node tests/voiceCommand.mjs`, `npx tsc --noEmit`

### 2단계: 음성 인식 후 즉시 자동 저장 및 피드백 개선 (`src/components/VoiceLogButton.tsx`)
- `result` 이벤트 수신 후 명령 파싱이 성공하면, 추가 클릭 없이 즉시 `save()` 자동 호출
- 기본값이 이미 채워져 있으므로 필수 입력 누락 경고 제거
- 저장 진행 중 UI 피드백("저장 중이에요…") 및 저장 완료 시 직관적 완료 피드백("🍼 분유 160ml 저장 완료!")
- 실패/오류 시 명확한 오류 안내
- 지원되는 명령어 가이드를 버튼 아래에 시각적으로 상시 제공 (또는 펼침 안내)
- 검증: `npx tsc --noEmit`

### 3단계: 테스트 케이스 확장 및 전체 회귀 검증
- `tests/voiceCommand.mjs`에 새로운 자연어 발화 케이스(단위 생략, 쉬했어, 응가했어, 맘마 140 등) 대폭 추가
- 임시 코드 변이(mutation) 테스트로 검증 유효성 확인 후 원복
- 기존 오프라인 테스트 및 번들 검사 실행
- 검증: `node tests/voiceCommand.mjs`, `node tests/autoVoiceLaunch.mjs`, `node tests/voiceFeedback.mjs`
