# 음성 기록 포용력 확대 및 즉시 저장 요구사항

## 목표
1. **음성 인식 후 즉시 자동 저장**: 두 손을 못 쓰는 육아 상황에서 불필요한 확인/저장 탭 없이, 유효한 음성 명령 해석 즉시 자동으로 기록을 저장하고 완료 안내를 제공한다.
2. **수동 입력과 음성 기록의 일관성 (기저귀/목욕 기본값)**:
   - 기저귀 수동 입력(소변/대변)과 동일하게, 상세 속성(소변 젖은정도/색, 대변 색상/형태/양)을 말하지 않더라도 기본값(`wetness: 'medium', color: 'normal'`, 대변 `color: 'yellow', consistency: 'soft', amount: 'medium'`)으로 즉시 저장되도록 하여 사용자에게 추가 입력을 요구하며 차단하지 않는다.
   - 목욕 역시 시간(분)을 말하지 않으면 기본값(`bathType: 'full', durationMinutes: 10`)으로 즉시 기록할 수 있도록 지원한다.
3. **명령어 포용력 확대 (자연어 유연성)**:
   - 어미 변형, 조사 생략, "응가했어", "쉬했어", "오줌 쌌어", "기저귀 갈았어(기본 소변)", "분유 160", "맘마 140", "수유 120" 등 일상적인 육아 표현을 폭넓게 인식한다.
   - 수면/터미타임/놀기 역시 "아기 잔다", "잠든다", "일어남", "기상", "낮잠 시작" 등 유연하게 처리한다.
4. **사용 가능한 명령어 예시 직관적 안내**:
   - 사용자가 무엇을 말할 수 있는지 음성 버튼 영역 또는 도움말에 주요 명령어 표현 가이드를 명확하고 간결하게 노출한다.

## 하지 않을 것
- OpenAI / Gemini 등 외부 유료 LLM 실시간 API 호출 (온디바이스/오프라인 음성인식 유지).
- 기존 수동 입력 화면의 UI 디자인 전면 개편.
- 잘못된 인식(unknown) 시 무분별한 저장. (인식 실패나 알 수 없는 발화는 즉시 피드백 후 저장하지 않음)

## 성공 기준
- "소변 봤어", "쉬했어", "대변", "응가 완료" 발화 시 별도 색상/양 선택 팝업 없이 즉시 기본값으로 저장됨.
- "분유 160", "맘마 140 먹었어" 등 다양한 자연어 표현 해석 성공.
- 인식 완료 후 손으로 버튼을 누르지 않아도 즉시 저장이 수행되고 안내 텍스트/음성 완료 안내 노출.
- UI에 지원되는 명령어 가이드가 노출됨.
- 기존 단위 테스트 및 새로운 자연어 케이스를 포함한 테스트 통과.

## 운영 위험 및 고려사항
- 즉시 저장 시 잘못 인식되었을 때 사용자가 인지할 수 있도록 저장 완료 안내와 토스트/메시지를 명확히 띄워야 함.
- 진행 중인 수면/터미타임/놀기 상태와 맞지 않는 명령(이미 자고 있는데 수면 시작 등)일 경우 적절한 오류 안내 필요.
