# 음성 기록 포용력 확대 및 즉시 저장 설계

## 1. 아키텍처 및 데이터 흐름 결정

### (1) 음성 인식 후 즉시 자동 저장 흐름
- 기존 흐름: `result` 수신 → `parseVoiceCommand` → 상태 `ready` → 화면에 확인 창 노출 → 사용자가 수동으로 "기록 확인" 버튼 탭 → `save()`.
- 개선 흐름:
  1. `result` 수신 (`isFinal === true`)
  2. `parseVoiceCommand(transcript)` 실행
  3. `parsed.kind !== 'unknown'`인 경우:
     - 상태를 `saving`("명령을 저장하고 있어요…")으로 설정
     - 검증(진행 중인 활동 상태 등) 수행
     - 누락된 필드는 수동 화면의 기본값으로 자동 채움
     - 즉시 `onAddLog` / `onUpdateLog` 호출
     - 저장 성공 시 완료 메시지 표시 ("분유 160ml 저장 완료" 등) 및 3초 후 `idle`로 복귀
  4. `parsed.kind === 'unknown'`인 경우:
     - 오류 상태 및 이해하지 못한 내용과 추천 명령어 안내

### (2) 수동 입력 기본값과의 일관성 (Defaults Alignment)
- `LogDiaper.tsx` 분석 결과:
  - 수동 소변: wetness 기본값 `medium`, color 기본값 `normal` (화면상 단순 교체 카드 형태)
  - 수동 대변: color 기본값 `yellow`, consistency 기본값 `soft`, amount 기본값 `medium`
  - 수동 목욕(`LogBath.tsx`): 기본 duration `10`분, bathType `full`
- `VoiceCommand` 파싱 및 저장 시:
  - 소변: wetness 미지정 시 `medium`, color 미지정 시 `normal` 자동 부여
  - 대변: color 미지정 시 `yellow`, consistency 미지정 시 `soft`, amount 미지정 시 `medium` 자동 부여
  - 목욕: duration 미지정 시 `10`분 자동 부여
  - 더 이상 `VoiceLogButton.tsx`에서 "정보 입력 필요: 미입력 항목을 선택한 뒤 기록해 주세요"라며 경고창을 띄우지 않고, 즉시 기본값으로 저장함. (말했을 경우엔 해당 값 반영)

### (3) 파서 포용력 (자연어 유연성 확대)
`src/utils/voiceCommand.ts` 개선:
1. **수유 / 분유 / 모유**:
   - "분유 160", "맘마 140", "우유 120", "모유 100", "수유 150ml 먹었어", "160 분유 먹음" 등
   - "ml", "미리", "밀리" 단위 생략 가능 (숫자와 수유 키워드 조합 지원)
   - "먹었어", "먹음", "완료", "마셨어", "먹였어" 외에도 단순 "분유 160" 형태도 허용
2. **소변**:
   - "소변", "오줌", "쉬", "쉬야", "소변 봤어", "쉬했어", "오줌 쌌어", "기저귀 갈았어", "소변 기저귀", "쉬야함" 등
3. **대변**:
   - "대변", "응가", "똥", "대변 봤어", "응가했어", "똥 쌌어", "응가함", "대변 기저귀" 등
   - 색상, 묽기, 양 언급이 있으면 파싱하고 없으면 기본값으로 매핑
4. **수면 / 터미타임 / 놀기**:
   - 수면 시작: "자", "잔다", "잠들어", "잠들었어", "수면 시작", "낮잠 시작", "밤잠 시작", "재웠어"
   - 수면 종료: "깼어", "일어났어", "기상", "수면 끝", "수면 종료", "낮잠 끝"
   - 터미타임: "터미타임", "엎드려 놀기" + 시작/끝
   - 놀기: "놀기", "놀이" + 시작/끝
5. **목욕**:
   - "목욕", "목욕했어", "씻겼어", "목욕 10분", "씻기 완료" 등
6. **체중**:
   - "몸무게 6.2kg", "몸무게 6.2", "체중 5.8키로", "체중 6킬로"

### (4) 명령어 가이드 UI 노출
- `VoiceLogButton.tsx` 컴포넌트 하단 또는 도움말 영역에 아코디언/칩 형태로 지원하는 대표 명령어를 항상 볼 수 있게 표시:
  - 🍼 분유/모유: "분유 160", "모유 100"
  - 💧 소변: "소변 봤어", "쉬했어"
  - 💩 대변: "대변 봤어", "응가했어"
  - 😴 수면: "지금 자", "지금 깼어"
  - 🛁 목욕/체중: "목욕 10분", "몸무게 6.5kg"
  - ⏱️ 활동: "터미타임 시작/끝", "놀기 시작/끝"

## 2. 독립 검토 결과
- 검토 항목:
  1. 즉시 저장 시 사용자가 인식 오류를 발견하지 못할 위험:
     → 저장 성공 시 토스트 또는 명확한 시각적 성공 배너("🍼 분유 160ml 저장 완료!")를 표시하여 사용자가 쉽게 인지할 수 있도록 함.
  2. 수동 기저귀와의 일치성:
     → 수동 화면도 기본값(`yellow`, `soft`, `medium` / `medium`, `normal`)으로 즉시 저장할 수 있는 구조이므로 음성과 완벽히 일치함.
  3. 오인식 방지:
     → 부정어("안 먹었어", "못 잤어") 및 모호한 문장("소변인가?")은 여전히 `unknown`으로 필터링하여 안전성 유지.
