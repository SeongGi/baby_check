# Play Alpha 출시: 음성 즉시 자동 저장 및 포용력 확대

- 대상: 아기기록 `com.seonggi.babycheck`, 비공개 테스트 Alpha.
- 버전: 1.7.7 / code25.
- 변경:
  - 음성 인식 후 별도 확인 터치 없이 즉시 자동 저장 (두 손 사용 불가 상황 개선).
  - 수동 입력 화면과 동일한 기본값 자동 적용 (소변/대변 시 색상·양 추가 질의 없이 즉시 저장).
  - 일상 대화형 명령어 포용력 확대 ("분유 160", "맘마 140", "쉬했어", "응가했어", "낮잠 시작" 등).
  - 사용 가능한 명령어 예시 안내 UI 추가.
- 출시 노트:
  “음성 인식 후 확인 터치 없이 바로 기록이 저장되도록 개선했습니다. 쉬했어, 응가했어, 맘마 140 등 일상적인 음성 명령을 더욱 폭넓게 인식합니다.”
- 사용자 데이터 보존: Google Play 업데이트 경로로 설치하며 기존 앱 삭제나 데이터 초기화를 하지 않는다.
