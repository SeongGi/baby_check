# 전체 코드 점검 요구사항

## 목표
- 현재 master의 핵심 기능을 코드와 재현 가능한 검사로 점검한다.
- 실제 사용자 데이터 손실, 잘못된 기록, 동기화 불일치, 음성·알림 오작동으로 이어질 수 있는 버그를 수정한다.
- 발견한 문제의 재현 조건과 검증 결과를 남긴다.

## 범위
- 저장·동기화·백업·복원, 기록 입력·수정·삭제, 음성 입력, 알림·앱 시작 경로, 버전·빌드 설정.
- 독립 검토 결과와 현재 테스트 실패를 우선한다.

## 하지 않을 것
- 재현 근거가 없는 대규모 리팩터링, 새 기능 추가, 저장 데이터 파괴, 프로덕션 배포.
- 이미 Google Play Alpha 검토 중인 1.7.2의 번들을 교체하지 않는다.

## 성공 기준
- 확인된 중대 버그를 수정하고 회귀 검사를 통과한다.
- TypeScript, 관련 오프라인 테스트, Android 번들 검증을 통과한다.
- 임시 코드 변이로 핵심 검사가 실제 오류를 감지함을 확인하고 즉시 원복한다.

## 운영 위험·열린 질문
- 연결된 Android 기기가 없어 Google 호출과 기기 알림·권한 흐름은 실제 기기에서 최종 확인해야 한다.
- Firebase 실제 서비스 검사는 사용자 데이터에 영향을 줄 수 있어 우선 오프라인 회귀로 검증한다.
