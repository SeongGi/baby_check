# 점검 및 수정 설계

기준 검사(TypeScript, 음성 명령, 오프라인 동기화)는 통과했다. 독립 감사에서 확인된 다음 결함을 수정한다.

1. 수유 알림 갱신이 겹치면 이전 알림 ID를 둘 다 읽어 중복 예약한다. 갱신 요청을 직렬화하고 마지막 요청 결과만 남긴다. 권한 요청이 있는 중간 작업도 반드시 실행하며, 실패한 작업 뒤에도 다음 요청을 실행한다.
2. 기록 수정 저장 실패 뒤 편집창이 닫혀 입력이 사라진다. 저장 결과가 참일 때만 닫고 실패를 알린다. 활동 시작/종료의 연속 터치는 요청 중 잠금으로 중복 기록을 막는다.
3. 내보낸 백업의 기록을 삭제한 뒤 가져오면 삭제 표식 때문에 복원이 무시된다. 가져온 파일에 실제 기록이 있는 경우, 로컬 삭제 표식과 충돌하는 ID는 원본 ID와 기록 내용의 SHA-256으로 만든 안정적인 새 ID로 복원한다. 기존 삭제 표식은 유지해 클라우드의 옛 기록이 되살아나지 않게 한다. 반복 가져오기와 원본 ID가 같지만 내용이 다른 경우를 검사한다.
4. 가족 서버 삭제 예약은 현재 설정 화면 진입시에만 검사하지만 UI는 정확히 1시간 뒤 자동 삭제한다고 알린다. 예약 시간이 지난 상태에서 설정 화면이 활성화되거나 다시 열리면 검사·실행한다. 설정 화면에 머무를 때는 기한 타이머를 둔다. 앱이 종료되어 있을 때 서버가 실행해 주는 기능은 없으므로 문구를 실제 동작에 맞춘다. 상태 조회 오류는 예약 없음과 분리해 재시도 안내를 표시하고 삭제 버튼을 막는다. 실행 직전 서버 예약 상태를 재확인하며 중복 실행을 막는다.

공유 저장 포맷과 서버 규칙은 바꾸지 않는다. 각 결함은 호출 흐름과 재현 시나리오를 검사하며, 전체 관련 테스트와 Android 번들 출력을 확인한다.

## 독립 설계 검토

조건부 승인. 안정적인 복원 ID와 조회 오류 분리·실행 전 재확인을 설계에 반영했다.
