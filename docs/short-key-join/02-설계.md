# 짧은 가족 키 합류: 설계

- `src/database/sync.ts`에 `parseFamilyInviteLink(value)`를 둔다. 앞뒤 공백을 지운 값이 `^babycheck://family/([a-zA-Z0-9_-]{1,256})$`(대소문자 무시)에 맞으면 키를, 아니면 null을 돌려준다. 키의 대소문자는 바꾸지 않는다(서버가 소문자로 바꿔 해시한다).
- 두 진입점은 이 함수의 결과만으로 판정한다. 32자 16진수 검사와 `parseFamilySyncId` 호출을 뺀다.
- 서버 정규식(`server/src/index.ts:91`)과 같은 경계를 쓴다. 두 값이 달라지면 앱이 받은 링크가 서버에서 401이 된다.
- 바꾸지 않는 것: `parseFamilySyncId`(저장된 키 처리, 길이 상한 없음), 링크 만들기, 합류 흐름(`familyMigration.ts` joinFamily).
- 규모가 작아(코드 약 10줄) 설계 독립 검토는 구현 리뷰 2개로 갈음했다.
