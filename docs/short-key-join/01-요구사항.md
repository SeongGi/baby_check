# 짧은 가족 키 합류: 요구사항

- 배경: 예전 앱에서는 사용자가 직접 친 짧은 그룹 비밀번호가 가족 키로 쓰였다. 서버는 `467f2e6`부터 1~256자 키(영문·숫자·`_`·`-`)를 받지만, 앱의 합류 진입점 두 곳은 32자 16진수 초대 링크만 받는다. 그래서 짧은 키 가족은 새 기기를 합류시킬 수 없다.
- 성기님 결정(2026-11-03): "다음 버전에서 짧은 키 풀어줘".
- 요구사항
  1. 초대 링크를 눌러 들어올 때(`App.tsx`)와 설정 화면에 링크를 붙여넣을 때(`Profile.tsx`) 서버가 받는 키를 모두 받는다.
  2. 서버가 401로 거절할 키(형식 밖 문자, 257자 이상)는 받지 않는다.
  3. 링크가 아닌 입력(키만 붙여넣기)은 지금처럼 받지 않는다.
  4. 이미 연결된 기기, 서버, 저장, 이전 로직의 동작은 바꾸지 않는다.
