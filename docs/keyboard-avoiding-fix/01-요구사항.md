# 키보드 입력 시 화면 가림 방지 요구사항

## 1. 목표
- 수유 기록(`LogFormula.tsx`), 기저귀 기록(`LogDiaper.tsx`), 목욕 기록(`LogBath.tsx`), 체중 기록(`LogWeight.tsx`), 프로필(`Profile.tsx`) 등 메모 및 텍스트 입력 시 가상 키보드가 입력란을 가리지 않도록 전반적인 화면 구조를 개선한다.
- 사용자가 메모란을 탭했을 때 키보드가 올라와도 입력 내용과 저장 버튼 영역까지 부드럽게 스크롤하여 확인할 수 있어야 한다.

## 2. 하지 않을 것
- 수동 기록 화면들의 비즈니스 로직, 데이터 구조, 테마 색상 등의 변경은 하지 않는다.

## 3. 성공 기준
- Android 및 iOS 환경 모두에서 메모 및 텍스트 필드 포커스 시 키보드 위로 내용이 스크롤되어 가려지지 않음.
- 키보드가 떠 있는 상태에서도 스크롤 및 탭 인터랙션이 자연스럽게 동작 (`keyboardShouldPersistTaps="handled"`).
- TypeScript 타입 에러 없음 (`npx tsc --noEmit`).
- 기존 단위 테스트 및 동기화 테스트 통과.

## 4. 운영 위험
- 플랫폼별(iOS vs Android) `KeyboardAvoidingView`의 `behavior` 및 `keyboardVerticalOffset` 처리 차이로 인한 화면 떨림 또는 과도한 여백 발생 가능성 → iOS는 `'padding'`, Android는 기본(`undefined` or `'height'`/`adjustResize`와 조화) 및 적절한 `contentContainerStyle` 하단 패딩 확보.
