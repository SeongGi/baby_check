# 키보드 입력 시 화면 가림 방지 구현 계획

## 1. 구현 단계
- **1단계**: `LogFormula.tsx` 수정
  - `KeyboardAvoidingView`에 `behavior={Platform.OS === 'ios' ? 'padding' : undefined}`, `keyboardVerticalOffset={Platform.OS === 'ios' ? 64 : 0}` 설정
  - `ScrollView`에 `keyboardShouldPersistTaps="handled"`, `keyboardDismissMode="on-drag"` 추가
  - `styles.contentContainer`의 `paddingBottom`을 `40`에서 `140`으로 대폭 확장
- **2단계**: `LogDiaper.tsx` 수정
  - `LogFormula`와 동일한 패턴 적용 (`paddingBottom: 140`, `keyboardShouldPersistTaps="handled"`, `keyboardDismissMode="on-drag"`, `keyboardVerticalOffset`)
- **3단계**: `LogBath.tsx` 수정
  - 동일 패턴 적용 (`paddingBottom: 140`)
- **4단계**: `LogWeight.tsx` 수정
  - 동일 패턴 적용 (`paddingBottom: 140`)
- **5단계**: `Profile.tsx` 수정
  - 동일 패턴 적용 (`paddingBottom: 140`)
- **6단계**: 버전 올림
