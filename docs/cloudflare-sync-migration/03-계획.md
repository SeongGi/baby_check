# 03-계획: Cloudflare Workers + D1 무과금 동기화 전환 계획

## 1. 개요 및 마이그레이션 전략

Firebase Firestore 기반 동기화 로직을 Cloudflare Workers + D1 기반 경량 REST API로 점진적 전환합니다.
기존 사용자의 로컬 저장소(`AsyncStorage`) 데이터 구조 및 초대 링크 호환성을 100% 보존하며, 단계별 독립 검증을 수행합니다.

---

## 2. 커밋 단위 계획

### [Commit 1] Cloudflare Worker 백엔드 및 D1 스키마 구현 (`server/`)
* **목표**: Cloudflare Edge에서 동작하는 서버리스 REST API 및 D1 스키마 구축.
* **주요 변경 대상**:
  * `server/package.json`: Worker 및 개발용 Wrangler 의존성 설정.
  * `server/wrangler.toml`: Worker 라우트 및 D1 바인딩(`DB`) 설정.
  * `server/schema.sql`: `families`, `members`, `logs` D1 테이블 및 인덱스 정의.
  * `server/src/index.ts`:
    * `POST /api/family/connect`: 신규/기존 가족 연결.
    * `GET /api/family/token`: `changeToken`(`updated_at:last_client_id`), `profileUpdatedAt`, `deletionReadyAt` 반환.
    * `POST /api/family/sync`: LWW 충돌 해결 조건부 upsert, 묘비명(tombstone) 부활 방지, 프로필 갱신, 증분 풀 조회를 `db.batch()`로 원자적 실행.
    * `POST /api/family/delete-schedule`, `cancel-delete`, `delete`: 1시간 냉각 기간 기반 가족 삭제 수명주기 처리.
    * `GET /api/family/deletion-status`: 삭제 상태 반환.
* **검증**:
  * `server/` 디렉터리 내 TypeScript 컴파일 검사 (`npx tsc --noEmit`).
  * API 스키마 및 엔드포인트 응답 유닛 검증.

### [Commit 2] 모바일 클라이언트 Cloudflare REST 통신 모듈 구축
* **목표**: 앱 클라이언트에서 Cloudflare Worker와 통신하는 통신 레이어 작성.
* **주요 변경 대상**:

    * 네트워크 오류/타임아웃 핸들링 및 표준화된 에러 래핑.
  * `src/database/cloudConfig.ts`:
    * 배포된 Worker URL 엔드포인트 상수 및 개발/로컬 환경 설정.
* **검증**:
  * `npx tsc --noEmit`으로 클라이언트 타입 무결성 검증.

### [Commit 3] `src/database/sync.ts` 마이그레이션 (Firebase 의존성 격리)
* **목표**: `sync.ts` 내부를 Firestore SDK 대신 `cloudClient.ts`로 전환하고 기존 인터페이스 호환성 보존.
* **주요 변경 대상**:
  * `src/database/sync.ts`:
    * `syncWithCloud(...)`: `cloudClient.syncData(...)` 호출 및 LWW 병합, `supersededIds` 처리, `syncLedger` 업데이트.
    * `readFamilyChangeToken(...)`: `cloudClient.getSyncToken(...)` 호출.
    * `subscribeToCloudChanges(...)`: 90초 주기 토큰 조회 및 `changeToken`의 `last_client_id` 대조로 에코 루프 차단.
    * 가족 삭제 함수들(`scheduleFamilyDeletion`, `cancelFamilyDeletion`, `deleteFamilyCloudData`, `getFamilyDeletionStatus`)을 `cloudClient` 호출로 교체.
    * `family_not_found` 수신 시 `familyUnavailable: true` 반환 보장.
* **검증**:
  * `npx tsc --noEmit` 검사 통과.
