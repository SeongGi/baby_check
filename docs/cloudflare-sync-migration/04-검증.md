# 04-검증: Cloudflare Workers + D1 무과금 동기화 전환 검증 보고서

## 1. 검증 개요
Firebase Firestore 기반 동기화를 Cloudflare Workers + D1 REST API 기반 시스템으로 전환한 후, 다음 영역에 대해 종합 검증을 수행하였습니다:
1. TypeScript 정적 타입 컴파일 무결성 (앱 + 서버)
2. 프로필 공유 규칙 및 오프라인 보존 단위 테스트 (`verify.sh unit`)
3. 백그라운드 수유 알림 갱신 테스트 (`verify.sh reminder`)
4. 동기화 프로토콜 및 충돌 해결 회귀 테스트 (`verify.sh regression`)
5. 음성 명령 및 음성 피드백 테스트 (`tests/autoVoiceLaunch.mjs`, `tests/voiceCommand.mjs`, `tests/voiceFeedback.mjs`)
6. 코드 감도 검증을 위한 원복 가능한 임시 변이(Mutation) 검증

## 3. 원복 가능한 임시 코드 변이(Mutation) 검증

테스트 하네스가 실제 분산 데이터 충돌 및 역전을 감지할 수 있는지 검증하기 위해, `src/database/sync.ts`의 `mergeLogs` 함수에 의도적인 변이를 주입하여 검증을 수행하였습니다.

* **주입 변이**:
  `mergeLogs`의 타임스탬프 비교 연산자를 역전:
  ```diff
  - if (!current || candidateUpdated > currentUpdated ||
  + if (!current || candidateUpdated < currentUpdated ||
  ```
* **변이 검증 결과**:
  * 실행 명령어: `./tools/sync-harness/verify.sh regression`
  * 테스트 실패 확인:
    ```text
    AssertionError [ERR_ASSERTION]: 전체 대조 뒤에는 서버의 최신 값으로 수렴해야 한다
    111 !== 999
    at regression.mjs:218:8
    ```
  * 의도한 대로 하네스가 데이터 비수렴을 즉시 감지하여 차단함을 확인.
* **원복 후 결과**:
  * 코드를 정상 연산자(`candidateUpdated > currentUpdated`)로 원복.
  * `./tools/sync-harness/verify.sh regression` 재실행 결과 **24/24 PASS** 복구 확인.
