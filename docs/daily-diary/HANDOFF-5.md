## 3. 브라우저 조작 요령 (이번 세션에서 알게 된 것)
- 원스토어 화면은 `iframe` 안에 있다. `get_page_text`, `find`, `file_upload`로는 내용이 보이지 않으므로 `document.querySelector('iframe').contentDocument`로 읽고 쓴다.
- 원스토어 버튼은 브라우저 기본 `confirm`/`alert` 창을 띄워 탭을 멈추게 한다. 누르기 전에 바깥 창과 iframe 창의 `alert`/`confirm`을 문구를 기록하는 함수로 바꿔 둔다(`confirm`은 true를 돌려준다). 실제로 "상품등록하시겠습니까?", "저장하시겠습니까?" 같은 확인 문구였다.
- 파일 첨부는 성기님이 직접 한다. 로컬 서버에서 받아 오는 방법은 Chrome 권한 요청 때문에 쓰지 않는다.
- Play 파일 선택 창은 지난번 폴더를 기억한다. 같은 이름 파일이 여러 워크트리에 있으므로, 구분되는 이름의 사본을 바탕화면에 두고 고르게 한다.
