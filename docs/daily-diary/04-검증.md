## 5. 남은 일과 한계
- **실기기 확인 (승인 전):** 다음 항목은 화면으로 직접 봐야 확인할 수 있다.
  - 홈의 "오늘의 한 줄"
  - 일기 화면의 쓰기·고치기·지우기·댓글
  - 역할 미지정 안내
  - 미래 날짜 카드의 문구
  - 닫히는 창의 모양
  - 한글 키보드로 200자 경계까지 입력할 때(조합 중 거부되는 경우, iOS와 Android 모두)
  - 작은 화면에서 키보드가 저장 버튼을 가리는지
- **고치지 않은 낮음 지적:**
  - 프로필에 갔다가 뒤로 가면 일기 화면이 아니라 홈으로 간다.
  - 한도 근처에서 긴 글을 붙여 넣으면 아무 안내 없이 거부된다.
  - 저장 실패 이유(미래 날짜, 저장소 오류)를 구분하지 않고 같은 안내를 띄운다.
  - 입력 창 모양을 기억하는 값을 그리는 도중에 바꾼다. 지금 쓰임새에서는 문제가 없지만 React 규칙에서는 벗어난 방식이다.
- **시험 방식의 한계:**
  - Dashboard·Statistics의 거르기와 `App.tsx`의 `syncKey` 조건은 Node에서 불러올 수 없어서 소스 문자열로 확인한다. 그래서 서식만 바뀌어도 시험이 깨질 수 있다.
  - `verify.sh real`(실제 서버 코드를 쓰는 묶음)은 이번에 돌리지 않았고, offline 묶음 안의 실제 서버 시나리오로 대신했다.
- **작업 트리:** `node_modules`는 `../baby-check-cloudflare/node_modules`를 가리키는 링크이며 커밋하지 않았다. 링크를 지울지는 승인 전이다.
