# 설계

음성 인식 시작부터 종료 후 5초까지 앱의 foreground 복귀를 자동 실행 후보로 만들지 않는다. 인식 시작 때 60초 상한을 둔다. 자동 시작 요청 소비와 실제 인식 이벤트는 기존 흐름을 유지한다.

자동 시작 요청은 시스템 인식기를 열기 전에 소비한다. 인식기가 앱 상태를 바꾸거나 권한 화면이 열려도 같은 요청을 다시 실행하지 않는다.

검토: 음성 인식 UI가 앱 상태를 바꾸더라도 복귀 직후 후보가 생성되지 않으며, 보류된 요청이 반복되지 않는다. 60초 이상 인식 화면이 유지되는 드문 경우에는 재실행 가능성이 남아 있으며, 이는 기기 재현 테스트가 필요하다.
