# 아내 휴대전화 설정

현재 Google Home 가족 자동화는 `home.command.Notification`의 `members`를 지정하지 않아 홈 구성원 모두에게 알림을 보낸다. 두 휴대전화에 같은 MacroDroid 매크로를 켜면 같은 문구에 두 앱이 함께 열린다.

1. 아내 Google 계정을 같은 Google Home의 구성원으로 추가하고, 아내 휴대전화에서 Google Home 앱 알림을 허용한다.
2. 아내 휴대전화에 아기기록 최신 비공개 테스트 버전과 MacroDroid를 설치한다.
3. MacroDroid에 알림 접근 권한과 다른 앱 위에 표시 권한을 허용한다.
4. 새 매크로: 트리거 `알림을 받으면` → 앱 `Home` → 알림 내용에 `BABYCHECK_START` 포함. 작업 `앱 실행` → `com.seonggi.babycheck`.
5. Google Home에서 `헤이 구글, 육아 기록 시작`으로 시험한다. 먼저 아내 휴대전화의 Home 알림 수신을 확인하고, 다음으로 매크로 실행 기록과 앱 열림을 확인한다.

원한다면 가족 자동화에 별도 시작 문구와 `members`를 지정해 한 휴대전화만 알림을 받도록 분리할 수 있다. 아내의 Google Home 계정 정보와 원하는 문구가 필요하다.

참고: [Google Home 알림 작업](https://developers.home.google.com/automations/schema/reference/entity/sht_structure/notification_command), [MacroDroid 알림 트리거](https://www.macrodroidforum.com/wiki/index.php?mobileaction=toggle_view_desktop&title=Trigger%3A_Notification).
