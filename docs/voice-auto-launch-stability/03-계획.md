# 구현 계획

1. 인식 시작/종료 이벤트를 앱 자동 실행 판단에 전달한다. 검증: `npx tsc --noEmit`.
2. 인식 중 및 종료 직후 앱 상태 전환을 자동 실행 후보에서 제외한다. 검증: `node --experimental-strip-types tests/autoVoiceLaunch.mjs`.
3. 자동 시작 요청을 음성 인식기 실행 전에 소비한다. 검증: `npx tsc --noEmit`와 코드 검토.
4. 기기 상태와 로그를 확인한다. 검증: ADB `dumpsys window`, `dumpsys activity exit-info`.
