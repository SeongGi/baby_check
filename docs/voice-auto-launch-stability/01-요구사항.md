# 자동 음성 시작 안정화 요구사항

- 목표: 앱 자동 음성 시작 사용 중 화면 전환을 새 앱 실행으로 오인해 듣기를 반복하지 않게 한다.
- 목표: 시스템 음성 인식 UI 전환 중 보류된 자동 요청을 반복 실행하지 않게 한다.
- 목표: Google Home 알림 후 앱 실행 상태와 잠금 화면 제약을 확인한다.
- 범위 밖: 잠금 해제 우회, Google Home에서 임의 앱 직접 실행.
- 성공 기준: 음성 인식 화면 복귀가 자동 시작을 재예약하지 않고, 기존 자동 시작 상태 테스트와 타입 검사를 통과한다.
- 운영 위험: 짧은 시간 안에 앱을 다시 열면 자동 듣기가 한 번 생략될 수 있다.
- 열린 질문: 사용자가 본 종료 시각의 예외 로그가 확보되지 않아 실제 크래시 원인은 확정하지 못했다.
- 아내 휴대전화는 별도 설치와 권한 설정이 필요하다. 동일한 가족 알림을 받으면 두 휴대전화 모두 반응할 수 있다.
