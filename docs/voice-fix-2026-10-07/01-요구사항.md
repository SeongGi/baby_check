# 업데이트 후 음성 동작 실패 요구사항

## 목표
- 설치된 Google Play Alpha 빌드 1.7.2에서 음성 기능이 작동하지 않는 보고를 재현 가능한 단계로 분리한다.
- 앱 전경 복귀와 음성 인식 시작 요청 사이의 확인된 누락 경로를 수정한다.
- 음성 인식 실패 원인이 기기 서비스·권한·앱 상태 중 어디인지 화면에서 구별할 수 있게 한다.

## 성공 기준
- 앱이 초기 실행 또는 백그라운드 복귀 뒤 설정을 켠 상태라면, 홈 화면이 active가 된 뒤 음성 입력 시작 요청을 정확히 한 번 전달한다.
- Assistant 화면/권한 화면 때문에 시작이 지연돼도 요청이 사라지지 않는다.
- 앱 안 마이크는 권한·서비스 오류를 구체적으로 안내하고 사용자가 다시 시도할 수 있다.
- TypeScript, 음성 명령 검사, 오프라인 회귀 및 Android 번들·네이티브 빌드를 통과한다.

## 제약과 위험
- Google App Actions의 한국어 사용자 지정 명령과 OPEN_APP_FEATURE는 공식적으로 지원되지 않는다. Google의 일반 앱 열기 명령이 앱을 열었을 때 앱 내부 인식으로 이어지는 흐름만 제공할 수 있다.
- 앱 종료 중 상시 청취나 백그라운드 마이크는 구현하지 않는다.
- 연결된 Android 기기가 없어 실제 Google/Gemini 음성 호출과 마이크 권한은 사용자 기기로 최종 확인한다.
- 사용자 증상의 정확한 단계는 질문으로 확인 중이다.

## 추가 확인: 업데이트 버튼
- Play Console에서 현재 테스터 제공 버전은 1.7.1(코드 19), 1.7.2(코드 20)는 검토 중임을 확인했다.
- 앱의 업데이트 버튼은 현재 버전을 1.7.0으로 고정하고 GitHub APK를 설치한다. 사용자가 Play 업데이트를 기대할 때 오래된 APK로 이동할 위험이 있다.
- 이 버튼은 실제 설치 버전을 보여주고 Google Play의 앱 페이지로 이동해야 한다. Play에 업데이트가 있는지는 Play에서 판단한다.
