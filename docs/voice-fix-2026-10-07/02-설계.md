# 음성 복귀 경로 수정 설계

1. MainApp은 자동 시작 후보를 active 상태일 때만 소비한다. 800ms 지연 중 Assistant 화면으로 앱이 비활성화되면 후보를 유지하고 다음 active 이벤트에서 다시 평가한다. 최초 `AppState.currentState`가 null/unknown이어도 같다.
2. 홈 외 화면에서는 후보를 폐기한다. 자동 듣기 토글을 켠 직후에는 현재 후보를 폐기해 다음 앱 실행·복귀부터 동작하게 한다.
3. MainApp에서 컴포넌트로 전달한 요청은 ID로 식별한다. VoiceLogButton은 `ExpoSpeechRecognitionModule.start()` 호출에 성공하거나 권한 거부·서비스 없음·네이티브 오류처럼 확정 종료되었을 때만 처리 완료로 알린다. 권한창 전환이나 앱 비활성 중단은 pending으로 유지한다. 이전 시도가 비동기 완료되더라도 새 요청을 지우지 않도록 MainApp은 같은 ID일 때만 요청을 지운다.
4. 권한 화면 때문에 앱이 잠시 background가 된 경우 VoiceLogButton의 기존 시도는 취소되며, active 복귀 후 남은 요청을 다시 시도한다. 이미 듣는 중이면 추가 세션을 만들지 않는다. 앱 상태·시도 종료에 따라 대기 요청을 다시 평가한다.
5. 인식 불가, 권한 거부, 네이티브 오류의 원인을 화면에 남겨 사용자가 수동 버튼으로 재시도하거나 기기 설정을 확인할 수 있게 한다.

## 독립 설계 검토

1차: MainApp 타이머가 inactive에서 후보를 소모하고 VoiceLogButton도 실제 시도 전 요청을 완료 처리하는 경로를 지적. 권한 화면 복귀 중복, 최초 null/unknown, 홈 이탈도 검증하도록 수정했다.
2차: 권한 요청을 시작한 시점에는 요청을 완료 처리하지 않도록 보완했다. 재검토 대기 중.

## 추가 설계: 업데이트 경로
- `expo-application`의 `nativeApplicationVersion`과 `nativeBuildVersion`으로 설치된 버전을 표시한다.
- 버튼은 Google Play 앱의 `market://details?id=com.seonggi.babycheck`를 우선 열고 실패하면 공식 HTTPS 상세 페이지를 연다. Google Play의 버전 상태를 앱이 임의 판정하지 않는다.
- 오래된 GitHub Releases APK 다운로드·설치 기능과 OTA라는 잘못된 문구를 제거한다. 기존 1.7.1에는 이 수정이 없으므로 사용자는 Play 앱에서 직접 업데이트해야 한다.
