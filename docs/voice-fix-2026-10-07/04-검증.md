# 음성 수정 검증

## 확인된 문제

- 기존 앱은 자동 시작 후보를 800ms 뒤 앱이 아직 background여도 소비했다. Assistant나 권한 화면이 앱 앞에 남아 있으면 음성 시작 요청이 사라진다.
- 음성 버튼 컴포넌트도 실제 인식을 시작하기 전에 요청을 완료 처리했다. 앱 상태가 바뀐 경우 다시 시도할 경로가 없었다.
- 인식 서비스·권한·네이티브 오류가 모두 일반적인 안내로 표시되어 기기에서 원인을 구별하기 어려웠다.

## 수정

- 앱이 active가 될 때까지 후보를 보존하고, 초기 AppState가 unknown/null이어도 다시 평가한다.
- 음성 요청을 ID로 처리해 이전 비동기 완료가 새 요청을 지우지 못하게 했다. 권한창 전환은 pending으로 유지하고, 수동 마이크가 시작되면 대기 중인 자동 요청을 소비한다.
- 인식 서비스 없음, 마이크 권한 거부, 네이티브 오류를 화면에 남긴다.
- 시험 버전을 1.7.3 / Android 코드 21로 올렸다.

## 검사 결과

- `npx tsc --noEmit`: 통과.
- `node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON tests/voiceCommand.mjs`: 8개 통과.
- `node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON tests/autoVoiceLaunch.mjs`: 8개 상태 사례 통과.
- `bash tools/sync-harness/verify.sh offline`: 통과.
- `npx expo export --platform android --output-dir /tmp/baby-check-voice-fix-export`: 통과.
- Android `:app:assembleDebug`: 통과, 약 2분. Gradle 생성 과정에서 기존 위젯 네이티브 파일이 바뀐 것은 원본으로 복원했다.
- 임시 변이: 비활성 앱을 `schedule`로 판정하도록 바꾸자 새 자동 시작 검사가 실패했다. 코드를 즉시 원복하고 재실행해 통과했다.
- 독립 설계 검토는 3차에서 승인. 독립 코드 리뷰 2건을 2회 진행했고 수동/자동 중복 요청 문제를 수정한 뒤 큰 지적이 없었다.

## 실제 기기 확인 필요

- 연결된 Android 기기가 없어 Play 설치 앱의 Assistant/Gemini 호출, 마이크 권한 화면, 한국어 실제 인식은 확인하지 못했다.
- 한국어 Google App Actions가 명령 전체를 앱에 전달하는 기능은 제공되지 않는다. 앱 열기 이후 앱 내부 음성 인식 방식이다.

## 추가 확인: 앱 업데이트 버튼

- Play Console에서 실제 제공 버전은 1.7.1(코드 19)이고, 1.7.2(코드 20)는 검토 중임을 읽기 전용으로 확인했다.
- 기존 버튼의 하드코딩 1.7.0 및 GitHub APK 다운로드 경로를 제거했다. 새 버튼은 설치된 네이티브 버전을 표시하고 Google Play 상세 페이지로 연다.
- 수정 후 TypeScript, Android JS 번들, `:app:assembleDebug`를 다시 통과했다. 업데이트 경로 독립 리뷰 2건에서 실제 코드 결함은 없었다.
- 새 버전이 Play Alpha에 제공되려면 Google 검토가 끝나야 한다. 기존 설치본의 업데이트 버튼은 여전히 오래된 동작이므로 Play 앱에서 직접 업데이트해야 한다.
