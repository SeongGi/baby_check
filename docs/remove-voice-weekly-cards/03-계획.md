## 음성기록 복원 방법

음성기록을 제거하기 직전의 master 커밋 `7d4753b`에 로컬 태그 `voice-last`를 달았습니다(원격에 올리려면 `git push origin voice-last`).

1. `git checkout voice-last -- src/components/VoiceLogButton.tsx src/utils/voiceCommand.ts src/utils/voiceFeedback.ts src/utils/autoVoiceLaunch.ts tests/voiceCommand.mjs tests/voiceFeedback.mjs tests/autoVoiceLaunch.mjs plugins/withOptionalMicrophone.js`
2. `npm install expo-speech-recognition`
3. app.json에 `expo-speech-recognition` 플러그인과 `./plugins/withOptionalMicrophone`를 되돌리고 `android.blockedPermissions`에서 RECORD_AUDIO를 뺍니다.
4. App.tsx와 Dashboard.tsx의 연결 코드는 `git diff voice-last -- App.tsx src/screens/Dashboard.tsx`로 보고 되살립니다.
5. 개인정보 처리방침의 음성 입력 항목을 되돌리고 Play Console 데이터 보안 항목을 다시 갱신합니다.

설계 기록은 `docs/voice-*`, `docs/all-voice-logs`, `docs/assistant-open-voice`에 남아 있습니다.
