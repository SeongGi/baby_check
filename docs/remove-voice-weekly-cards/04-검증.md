# 검증 (2026-11-27)

## 설계 검토

독립 검토를 세 번 받았습니다. 1차와 2차는 "수정 필요"였고 3차에서 승인받았습니다. 반영한 주요 지적은 다섯 가지입니다.
- 오늘을 주에서 뺐습니다.
- 기록 0건인 주는 평균을 null로 둡니다.
- 체중은 그 주에 잰 값만 씁니다.
- 폭을 재기 전에는 위치를 맞추지 않습니다.
- 선택 상태는 start 기준으로 들고 있습니다.

## 구현 리뷰 (독립 2개)

- **계산 리뷰:** 사양과 어긋나는 계산은 없었습니다. 낮음 3건과 테스트 구멍 4건이 나왔고 모두 반영했습니다.
  - 음수 반올림 비대칭은 절댓값으로 반올림하도록 고쳤습니다.
  - NaN timestamp와 NaN 상한을 걸러 냅니다.
  - 테스트 10~12를 더했습니다.
- **화면 리뷰:** 높음과 중간은 없었고 낮음 5건이 나왔습니다. 그중 4건을 고쳤습니다.
  - 빈 주의 "기록 없음"이 두 번 보이던 것을 한 번만 보이게 했습니다.
  - 값을 증감과 같은 자릿수로 표시합니다.
  - 처음 위치를 맞추기 전에는 카드 줄을 투명하게 둡니다.
  - 막대에 선택 상태를 넣었습니다.
  - 나머지 1건인 onLayout의 효과 없는 호출은 지우고 설계 문구를 실제 동작에 맞췄습니다.
  - 확인하지 못한 의심으로 남은 것: 넘기는 도중 동기화로 카드 장수가 바뀌면 보던 주로 되돌아갈 수 있습니다. 실기기에서 확인해야 합니다.
