## B. 주별 흐름 카드 (2차 설계, 1차 검토 지적 반영)

### 계산 모듈 `src/utils/weeklyCards.ts`

react-native를 import하지 않는 순수 함수입니다. 타입은 `import type`으로만 가져오고 다른 값 모듈도 import하지 않아 node 테스트로 바로 검증합니다.

```ts
export interface WeeklyDelta {
  formulaPerDay: number | null; feedsPerDay: number | null;
  sleepHoursPerDay: number | null; diapersPerDay: number | null;
}
export interface WeeklyCard {
  start: number;            // 주 시작(포함), 로컬 자정
  end: number;              // 주 끝(제외), 로컬 자정
  label: string;            // "11/20 ~ 11/26" (끝 날짜는 end 하루 전)
  isLatest: boolean;        // 가장 최근 주(어제로 끝나는 주)
  coveredDays: number;      // 평균의 분모가 되는 날 수(1~7)
  formulaPerDay: number | null;    // ml, 정수
  feedsPerDay: number | null;      // 소수 1자리
  sleepHoursPerDay: number | null; // 소수 1자리
  diapersPerDay: number | null;    // 대변+소변, 소수 1자리
  weightKg: number | null;         // 이 주에 잰 마지막 체중. 재지 않았으면 null
  weightDeltaKg: number | null;    // weightKg - 이 주 이전에 잰 가장 최근 체중. 소수 2자리
  delta: WeeklyDelta | null;       // 바로 앞 주 대비. 앞 주가 없거나 coveredDays 0이면 null
}
export function buildWeeklyCards(logs: BabyLogEntry[], now?: number, maxWeeks?: number): WeeklyCard[];
```

규칙:
- 주 구간은 **끝난 날만** 씁니다. 가장 최근 주는 `어제-6일 ~ 어제`이고 그 앞으로 7일씩 끊습니다. 오늘은 아직 끝나지 않아 어느 카드에도 들어가지 않습니다. 오늘이 끼면 이번 주 평균과 증감이 늘 낮게 나오기 때문입니다(1차 검토 지적). "최근 7일" 탭과 숫자가 다를 수 있으므로 카드에 "완료된 N일 평균"이라고 분모를 적습니다.
- 날짜 이동은 `Date#setDate`, 로컬 자정은 `setHours(0,0,0,0)`으로 맞춥니다(기존 Statistics.tsx와 같은 방식).
- **분모 `coveredDays`**는 주 안의 날 가운데 "첫 기록일 자정 이후"인 날 수입니다. 첫 기록일은 모든 기록의 최소 timestamp로 정합니다. 기록을 시작한 첫 주만 7보다 작고 나머지 주는 7입니다. 중간에 기록을 빠뜨린 날도 분모에 넣습니다. 기록 종류에 따라 분모가 흔들리지 않게 하려는 선택입니다.
- 카드 수: 첫 기록일이 든 주부터 최근 주까지, 최대 `maxWeeks`(기본 12)장입니다. 증감을 구하려고 내부에서는 한 주를 더 계산하고 반환할 때 뺍니다. 기록이 없거나 첫 기록일이 오늘이면(끝난 날이 없음) 빈 배열입니다.
- 반환 순서는 오래된 주 → 최근 주입니다. 화면 왼쪽이 과거입니다.
- 수유량은 formula 기록 `amount`의 합, 수유 횟수는 formula 기록 수입니다(timestamp가 구간 안).
- 기저귀는 urine과 stool 기록 수의 합입니다.
- 수면은 sleep 기록 `[timestamp, endedAt ?? now]`가 주 구간과 겹치는 분의 합입니다. 끝이 시작보다 앞서면 0으로 칩니다. 자정을 넘는 수면은 나눠 들어갑니다. 진행 중 수면은 now까지로 잡습니다. 기존 탭과 같은 동작이며 끝나지 않은 오늘 부분은 주 구간 밖이라 저절로 빠집니다.
- 평균은 `합 / coveredDays`를 표시 단위로 반올림합니다. 단 그 주 구간에 timestamp가 든 기록이 0건이면(기록을 통째로 빠뜨린 주) 평균 네 개를 모두 null로 둡니다. "기록 안 함"을 "안 먹음"과 구분하기 위해서입니다. 이런 주와 맞닿은 증감도 null이 됩니다.
- 첫 기록일은 하루 전체로 셉니다. 첫 기록이 밤늦게 있었다면 첫 주 평균이 조금 낮을 수 있습니다. 첫 주는 증감이 없으니 그대로 둡니다.
- 증감은 반올림한 두 값의 차를 **다시 같은 자릿수로 반올림**해 부동소수 오차를 없앱니다. 어느 한쪽이 null이면 그 항목은 null입니다.
- 체중: `weightKg`는 그 주 안에 잰 기록 중 마지막 값입니다. `weightDeltaKg`는 그 주에 잰 기록이 있고 그 이전에 잰 기록도 있을 때만 계산합니다(목록 상한과 무관하게 전체 기록 기준).

### 화면

`src/screens/Statistics.tsx`:
- `Range = 'week' | 'weekly' | 'all'`, 탭 순서는 `최근 7일 | 주별 흐름 | 전체`입니다.
- weekly일 때 분기 처리:
  - 부제: "한 주씩 넘기며 생활 패턴의 변화를 확인해요."
  - 기존 요약 카드, 막대 차트, all 전용 기간 카드, 성장 기록 카드, 체온 카드는 숨기고 `<WeeklyFlow logs={logs} />`만 보입니다. 체중은 주별 카드에 들어 있습니다.
  - 기존 `range === 'week' ? … : …` 삼항(부제, 최고 체온 구간, 라벨들)이 weekly를 all로 오인하지 않게 합니다. weekly에서는 그 요소들이 아예 렌더되지 않으므로 부제만 3갈래로 바꾸면 됩니다. 최고 체온 계산은 weekly에서 쓰이지 않습니다.

`src/components/WeeklyFlow.tsx`(새 파일):
- `cards = useMemo(() => buildWeeklyCards(logs), [logs])`.
- 선택 상태는 인덱스가 아니라 카드의 `start`로 들고 있습니다(카드 목록이 바뀌어도 보던 주 유지). 초기값은 `null`이고 null이면 마지막 카드로 봅니다. 선택한 start가 목록에서 사라지면 마지막 카드로 돌아갑니다.
- 페이지 폭은 가로 `ScrollView`의 `onLayout`으로 잰 너비 `pageWidth`를 씁니다. 카드 하나의 폭이 정확히 `pageWidth`이고 카드 사이 간격은 카드 안쪽 padding으로 만듭니다(바깥 margin 금지). `pagingEnabled`입니다.
- `pageWidth`가 0인 동안(아직 onLayout 전)에는 카드 줄을 그리지 않고 `x / pageWidth` 계산도 하지 않습니다.
- 위치 맞추기: `pageWidth > 0`이고 카드가 있을 때 선택 카드 위치로 `scrollTo({ x: index * pageWidth, animated: false })`합니다. `onLayout`은 폭만 기록합니다. 폭이 정해져 카드가 그려지면 반드시 `onContentSizeChange`가 오므로 위치 맞추기는 그 콜백이 합니다(구현 리뷰 반영: onLayout 시점에는 새 폭이 아직 state에 없어 그 호출은 효과가 없었습니다). 맞추기 전에는 카드 줄을 투명하게 둬 가장 오래된 주가 잠깐 보이지 않게 합니다. 이 함수는 `pageWidth`, 카드 start 목록, 선택 start로 만든 키가 지난번과 같으면 아무것도 하지 않습니다. 그래서 카드 목록이 바뀌면(동기화로 옛 주가 앞에 붙는 경우 등) 보던 주 위치로 다시 맞추고, 사용자가 넘긴 뒤에는 끌고 가지 않습니다. 카드 장수가 같아 두 콜백이 오지 않는 경우(12장 상한에서 앞 주가 빠지고 새 주가 붙음)를 위해 `cards`가 바뀔 때 도는 effect에서도 같은 함수를 부릅니다(3차 검토).
- `onMomentumScrollEnd`에서 `Math.round(x / pageWidth)`로 선택 start를 갱신합니다. 버튼이나 막대로 이동할 때는 선택을 먼저 바꾸고 `scrollTo({ animated: true })`합니다.
- 카드 내용: 기간 라벨(최근 주면 "최근 1주" 배지), "완료된 N일 평균", 🍼 하루 수유량(ml)과 횟수, 🌙 하루 수면(시간), 🧷 하루 기저귀(회), ⚖️ 체중(그 주에 잰 값과 이전 측정 대비 증감, 없으면 "이 주 측정 없음"). 값 오른쪽에 증감을 보입니다: 양수 `▲40`, 음수 `▼0.5`, 0 `±0`, null이면 보이지 않음. 증감 색은 좋고 나쁨을 뜻하지 않게 중립으로 둡니다(▲ COLORS.primary, ▼ COLORS.secondary, ±0 COLORS.textMuted).
- 카드 아래: 점 표시(선택 강조)와 `‹ 지난주`, `다음 주 ›` 버튼. 끝에서는 비활성화하고 `accessibilityState.disabled`를 줍니다.
- 그 아래 "주별 하루 수유량" 막대 줄: 주마다 막대 하나(formulaPerDay, null이면 빈 막대), 선택 주 강조, 누르면 그 주로 이동합니다. 막대 아래 라벨은 주 시작 날짜 `M/D`입니다.
- 빈 상태: logs가 없으면 "아직 저장된 기록이 없어요.", 기록은 있지만 카드가 없으면(오늘 처음 기록) "하루가 지나면 첫 주 카드가 만들어져요."
- 화면을 연 채 자정을 넘기면 카드가 갱신되지 않습니다. 탭을 옮기면 다시 계산되므로 받아들입니다.
- 스타일은 기존 관례(StyleSheet, COLORS, 카드 borderRadius 22, border COLORS.border)를 따릅니다.

### 테스트 `tests/weeklyCards.mjs`

node 내장 `assert`로 확인합니다.
1. 빈 기록 → `[]`. 오늘만 기록이 있음 → `[]`.
2. 최근 주 구간이 `어제-6 ~ 어제`이고 라벨 끝 날짜가 어제입니다. 오늘 기록은 어느 카드에도 들어가지 않습니다.
3. 오래된 → 최근 순서이고 마지막만 `isLatest`입니다.
4. 기록이 20주 전부터 있으면 12장이고 맨 앞 카드에도 `delta`가 있습니다.
5. 첫 주 `coveredDays`가 첫 기록일부터 센 날 수입니다. 평균이 그 값으로 나뉩니다.
6. 자정을 넘는 수면이 두 주에 나뉘어 들어갑니다. 진행 중 수면은 now까지 잡히되 오늘 부분은 빠집니다. 끝이 시작보다 앞선 기록은 0입니다.
7. 증감: 반올림 후 차이(예: 2.3 vs 2.1 → 0.2 정확히). 앞 주 coveredDays 0이나 맨 첫 주는 `delta === null`입니다.
8. 중간에 기록이 0건인 주: 평균이 모두 null이고 그 주와 다음 주의 delta 항목이 null입니다.
9. 체중: 그 주 측정이 없으면 `weightKg === null`. 측정이 있으면 이전 측정 대비 증감이 소수 2자리입니다.

`package.json`에 `"test": "node tests/weeklyCards.mjs"`를 더합니다.
