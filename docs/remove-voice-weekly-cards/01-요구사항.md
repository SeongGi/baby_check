# 음성기록 제거와 주별 흐름 카드: 요구사항

## 배경

- 음성기록은 실제로 한 번도 쓰이지 못했습니다(2026-11-27 성기님). 기기 음성 인식이 육아 상황에서 안정적으로 동작하지 않았습니다.
- 통계 화면은 최근 7일과 전체 누적만 보여 줘서 주마다 패턴이 어떻게 바뀌는지 보기 어렵습니다.

## 목표

1. 음성기록 기능을 앱에서 모두 뺍니다. 버튼, 앱을 열 때 바로 듣기 설정, 음성 인식 패키지, 마이크 권한, 관련 테스트와 개인정보 처리방침 문구까지 정리합니다.
2. 통계 화면에 "주별 흐름" 탭을 더합니다. 한 주가 카드 한 장이고 옆으로 넘겨 지난주로 갑니다. 카드마다 하루 평균과 지난주 대비 증감을 보여 줍니다.

## 하지 않을 것

- 저장된 기록 데이터의 형식이나 동기화 로직은 바꾸지 않습니다(실사용 가족 데이터 보전).
- 기존 "최근 7일"과 "전체" 탭의 계산은 바꾸지 않습니다.
- 버전 번호 올리기, 빌드, 스토어 제출, 푸시와 PR은 이번 범위가 아닙니다.
- 음성 기능을 설정으로 꺼 두는 방식은 쓰지 않습니다. 패키지와 권한이 남기 때문입니다.

## 성공 기준

- 소스, app.json, package.json, package-lock.json, 추적 중인 AndroidManifest.xml에 음성 인식과 마이크 관련 항목이 남지 않습니다. 예외는 docs/ 아래 과거 기록 문서와 마이크 권한을 막는 app.json `android.blockedPermissions` 항목, 남은 설정값을 지우는 App.tsx의 레거시 키입니다.
- 홈 화면의 빠른 기록 버튼들은 그대로 동작합니다.
- 통계 화면에 탭이 셋(최근 7일, 주별 흐름, 전체) 있고 주별 흐름 탭에서 카드를 넘길 수 있습니다.
- 주별 계산 함수에 단위 테스트가 있고 타입 검사(tsc --noEmit)가 통과합니다.
- 나중에 복원할 수 있도록 제거 직전 커밋에 `voice-last` 태그를 남기고 복원 방법을 03-계획.md에 적습니다.

## 운영 위험

- 마이크 권한이 빠지므로 Play Console 데이터 보안 항목과 호스팅 중인 개인정보 처리방침도 갱신해야 합니다. 앱 출시 때 함께 처리합니다.
- 기존 사용자의 기기에 `@babycheck/autoVoiceOnOpen` 값이 남습니다. 앱이 한 번 지워 줍니다.
