# 앱 내 음성 기록 반응 복구

## 목표
- 홈의 음성 버튼을 누르면 즉시 시작 상태를 표시하고, 듣기·명령 처리·저장 전 확인 또는 오류까지 진행 상태를 보여준다.
- 이미 허용된 마이크 권한은 다시 요청하지 않는다.
- 기존 수유·기저귀·목욕·몸무게·수면·터미타임·놀기 명령과 저장 전 확인 절차를 유지한다.

## 제외
- Google Home 스피커 연동과 자동 서버 기록은 이번 작업에 포함하지 않는다.
- 테스트용 아기 기록을 실제 서버에 저장하지 않는다.

## 성공 기준
- 수동 버튼을 눌렀을 때 무반응으로 보이지 않는다.
- 권한 거부, 인식 서비스 없음, 앱 이탈, 인식 오류가 화면에 구별되어 표시된다.
- 전사된 문장을 표시하고 명령을 처리한 뒤 기존 확인 화면으로 이동한다.
- 타입 검사, 음성 명령 검사, 상태 검사, Android 번들이 통과한다.

## 위험과 열린 질문
- 삼성 기기의 음성 인식 서비스가 내는 상태 이벤트 순서는 실기기 확인이 필요하다.
- 실제 발화 인식과 기록 저장은 사용자가 최종 확인한다.
