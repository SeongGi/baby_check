## 5. 알고 있는 한계 (리뷰의 낮음 지적, 코드는 그대로 둠)
- 알림 안내창을 60초 넘게 두면 프로필 화면의 "저장 완료" 창이 뜬다. Android는 새 창을 띄울 때 안내창을 닫으므로 알림은 미허용으로 남는다. 이때는 알림을 껐다가 다시 켜면 된다. 그 60초 동안 저장 버튼은 "저장 중"으로 남는다.
- 마이크 안내창이 떠 있는 채로 탭을 옮겼다가 돌아와 새로 녹음을 시작한 뒤 옛 안내창에 답하면, App의 음성 자동 시작 억제 시간이 60초에서 5초로 줄어든다. 실제로 시작이 겹치지는 않는다.
- 같은 실행 중에 취소한 뒤 자동 시작을 건너뛰면 직전 저장 요약 문구가 지워진다. 이 동작은 이번 변경 전부터 있었다.
- 안내창을 띄운 채 앱을 뒤로 보냈다 돌아오면 자동 시작이 두 번째 안내창을 띄울 수 있다. 어느 쪽에 답해도 마지막에 고른 쪽을 따른다.
- 첫 실행 안내를 뒤로 가기로 닫아도 확인한 것으로 저장한다. 실제 동의는 요청 직전 안내창에서 받기 때문이다.

## 6. 실기기 확인 목록 (빌드 뒤, 시험 기기에서만)
실사용 가족 휴대폰에는 시험 빌드를 설치하지 않는다.

1. 새로 설치: 첫 화면에 접근권한 안내가 한 번 뜨고, "확인" 뒤 앱을 다시 열어도 뜨지 않는다.
2. 1.8.1에서 업데이트: 안내가 한 번 뜬다. 기존 기록과 동기화가 그대로다.
3. 음성 자동 시작을 켠 채 업데이트: 안내가 떠 있는 동안 마이크 안내창이나 허용 창이 뜨지 않고, 안내를 닫으면 자동 시작이 이어진다.
4. 마이크 미허용 상태에서 음성 버튼: 앱 안내창 → "취소"면 허용 창이 뜨지 않는다. "계속"이면 허용 창이 뜬다. 이미 허용한 기기에서는 안내창 없이 바로 시작한다.
5. 마이크 안내창이 떠 있을 때 홈 버튼 → 앱 복귀 → "계속": 허용 창이 한 번만 뜨고 음성 기록이 시작된다. 같은 상황에서 "취소"면 허용 창이 뜨지 않는다.
6. 자동 시작을 켠 채 안내창에서 "취소" → 다른 탭으로 갔다 홈으로 복귀 → 앱을 뒤로 보냈다 다시 열기: 안내창이 다시 뜨지 않는다.
7. 알림 미허용 상태(Android 13 이상)에서 수유 알림을 켜고 저장: 알림 안내창이 먼저 뜨고, 답한 뒤에 "저장 완료"가 뜬다. 다음 수유 시간이 없어도 묻는다.
8. 알림이 이미 켜진 상태에서 이름만 바꿔 저장: 안내창이 뜨지 않는다.
9. 작은 화면에 글꼴을 최대로 키운 상태: 첫 실행 안내 본문이 스크롤되고 "확인" 버튼이 화면 안에 보인다.
10. 빌드 결과물의 권한: `aapt dump permissions <apk>`(또는 병합된 매니페스트)에 `READ_EXTERNAL_STORAGE`와 `WRITE_EXTERNAL_STORAGE`가 없다.
11. 처리방침: master에 머지한 뒤 GitHub Pages에서 07절과 "2026년 11월 2일 / 1.8.2"가 보인다.
