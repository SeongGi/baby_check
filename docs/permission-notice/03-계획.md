## 커밋 ① 순수 로직과 테스트
- 파일: `src/utils/permissionNotice.ts`(새 파일), `tests/permissionNotice.mjs`(새 파일), `package.json`의 `test:permission` 스크립트
- 내용: 설계 1절과 9절. 이 모듈은 다른 파일을 가져오지 않고 `enum`·`namespace`를 쓰지 않는다.
- 검증: `npm run test:permission`, `npx tsc --noEmit`

## 커밋 ② 사전 안내창과 마이크·알림 연결
- 파일: `src/utils/permissionPrompt.ts`(새 파일), `src/components/VoiceLogButton.tsx`, `src/utils/feedingReminder.ts`, `App.tsx`의 `handleSaveProfile`
